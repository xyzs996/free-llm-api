DeepSeek 系列是什么

DeepSeek 的 V3 与 R1 是被问得最多的开放权重推理模型，好几家服务商把它们放在免费层或赠送额度里。

以免费条款提供 DeepSeek 的服务商

本清单详列的 25 家服务商里，有 5 家至少提供一个 DeepSeek 模型。因为 DeepSeek 公开的是权重而不是服务，所以 model id 在这些家之间可以完全一致，免费额度却不一样。

服务商免费形式官方公布限额信用卡匹配到的模型
SambaNova Cloud 厂商免费额度 每分钟 20 次请求，每天 20 次请求 不需要 DeepSeek-V3.1
Hugging Face Inference Providers 厂商免费额度 以额度余额公布 不需要 deepseek-ai/DeepSeek-V3-0324
SiliconFlow 厂商免费额度 每分钟 1000 次请求 不需要 deepseek-ai/DeepSeek-R1
Nebius Token Factory 按量计费 每分钟 60 次请求 不需要 deepseek-ai/DeepSeek-V3
DeepInfra 按量计费 有限流但未公布数值 不需要 deepseek-ai/DeepSeek-V3

免费条款到底差在哪

  • SambaNova Cloud — 只要账号没有绑定支付方式，就处于 Free Tier。
  • Hugging Face Inference Providers — 登录的免费用户每月获得 0.10 美元的 Inference Provider 额度（Hugging Face 注明这个数额可能调整）；PRO 用户 2.00 美元，Team 或 Enterprise 组织按每席位 2.00 美元。
  • SiliconFlow — 免费模型的限流是固定值；付费模型按月消费分层，L0 起步为 1,000 RPM、40,000 TPM。
  • Nebius Token Factory — 限额是动态的，公布的基线为 60 RPM 和 400,000 TPM。
  • DeepInfra — 官方定价页为每个在服模型列出了每百万 token 的输入与输出价格，既没有描述免费额度，也没有公布请求速率限制。

怎么挑一家

这 5 家里有 3 家公布了固定的请求次数，其余的只给出层级或额度余额，也就是说「到底免费多少」唯一诚实的答案在它们各自的控制台里。有 5 家不要信用卡。有 4 家会响应跨域浏览器请求，所以这些家的 key 不用装任何东西，直接在浏览器检测页里就能验。

model id 匹配上 DeepSeek，并不等于承诺免费额度里就包含它。服务商会在不改 id 的情况下把某个模型在付费和免费之间挪动，所以每一行都链回对应的服务商页面，那里放着该服务商自己的原话和读取日期。
