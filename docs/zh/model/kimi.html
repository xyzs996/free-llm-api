以免费条款提供 Kimi 的服务商

本清单详列的 25 家服务商里，有 2 家至少提供一个 Kimi 模型。因为 Moonshot AI 公开的是权重而不是服务，所以 model id 在这些家之间可以完全一致，免费额度却不一样。

免费条款到底差在哪

  • Moonshot AI (Kimi) — 分档表挂钩的是累计充值金额，而不是一份长期免费额度：文档写明必须先充值至少 $1 才能开始使用，此后 Tier0 给 1 路并发、3 RPM、500K TPM、1.5M TPD。
  • Vercel AI Gateway — 每个 Vercel team 账号都有免费档，但免费档只覆盖模型子集，不是全部目录；免费档的请求还按模型限流，上限低于付费档，而这些按模型的数字并不公布。

怎么挑一家

这 2 家里有 0 家公布了固定的请求次数，其余的只给出层级或额度余额，也就是说「到底免费多少」唯一诚实的答案在它们各自的控制台里。有 2 家不要信用卡。有 2 家会响应跨域浏览器请求，所以这些家的 key 不用装任何东西，直接在浏览器检测页里就能验。

model id 匹配上 Kimi，并不等于承诺免费额度里就包含它。服务商会在不改 id 的情况下把某个模型在付费和免费之间挪动，所以每一行都链回对应的服务商页面，那里放着该服务商自己的原话和读取日期。
