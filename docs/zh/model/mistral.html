Mistral 系列是什么

Mistral AI 同时发布通用模型和 Codestral 代码模型；Mistral 官方 API 的免费条款与转托管开放权重的平台并不一样。

以免费条款提供 Mistral 的服务商

本清单详列的 25 家服务商里，有 4 家至少提供一个 Mistral 模型。因为 Mistral AI 公开的是权重而不是服务，所以 model id 在这些家之间可以完全一致，免费额度却不一样。

免费条款到底差在哪

  • Mistral La Plateforme — Mistral 文档里有一个 Free 模式（也称 Experiment 计划），不付费就能激活工作区并生成 API key，但公开文档目前没有一个打得开的限流页面：核验当天，Mistral 自己文档索引里给出的该层级 URL 返回 404。
  • Pollinations.AI — API 文档现在按「两次请求的最小间隔」公布了四档：Anonymous，免注册，基础模型，每 15 秒 1 次；Seed，免费注册，标准模型，每 5 秒 1 次；Flower，付费，高级模型，每 3 秒 1 次；Nectar，企业版，全部模型，不限。
  • IBM watsonx.ai — IBM 在付费的 Essentials 和 Standard 计划之外，提供 watsonx.ai 的免费试用，定价页也明确邀请你零成本开始构建。
  • Chutes — Chutes 按 token 计费，并出售包含每日额度的订阅计划：Plus 每月 10 美元，含一份每日额度，超出部分在按量价上打 94 折；Pro 每月 20 美元，每日额度更大，超出部分打 9 折。

怎么挑一家

这 4 家里有 1 家公布了固定的请求次数，其余的只给出层级或额度余额，也就是说「到底免费多少」唯一诚实的答案在它们各自的控制台里。有 4 家不要信用卡。有 3 家会响应跨域浏览器请求，所以这些家的 key 不用装任何东西，直接在浏览器检测页里就能验。

model id 匹配上 Mistral，并不等于承诺免费额度里就包含它。服务商会在不改 id 的情况下把某个模型在付费和免费之间挪动，所以每一行都链回对应的服务商页面，那里放着该服务商自己的原话和读取日期。
