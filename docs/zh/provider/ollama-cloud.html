怎么验一个 Ollama Cloud 的 key

该端点对 CORS 预检返回 405 且没有 allow-origin 响应头，所以浏览器拒绝把 Authorization 请求头发出去。这一结论是 2026-07-25 针对 https://ollama.com 实测得到的。

所以浏览器检测页够不着它，页面也不会假装够得着。请改用下面这条命令：

#!/usr/bin/env sh
set -eu

: "${OLLAMA_CLOUD_API_KEY:?Set OLLAMA_CLOUD_API_KEY to a key you created yourself at the provider console}"

# Prints the models this key can reach, then the HTTP status on its own line so
# 200, 401, and 429 stay distinguishable.
curl --silent --show-error \
  --write-out '\nHTTP %{http_code}\n' \
  --header "Authorization: Bearer $OLLAMA_CLOUD_API_KEY" \
  'https://ollama.com/v1/models'

怎么用一个 Ollama Cloud 的 key

Ollama Cloud 在 https://ollama.com/v1 上提供 OpenAI chat completions 协议。把任何支持自定义 base URL 的客户端指过去，并让客户端从 OLLAMA_CLOUD_API_KEY 读取 key，这样 key 本身永远不会落进配置文件：

# Merge this snippet into ~/.codex/config.toml.
# Project-level config cannot select a custom model provider.
model = "gpt-oss:120b-cloud"
model_provider = "ollama-cloud"

[model_providers.ollama-cloud]
name = "Ollama Cloud OpenAI-compatible gateway"
base_url = "https://ollama.com/v1"
env_key = "OLLAMA_CLOUD_API_KEY"
wire_api = "responses"

关于 Ollama Cloud 免费额度的常见问题

Ollama Cloud 需要绑信用卡吗？

不需要。本站有 23 家不用绑卡就能拿到免费访问，Ollama Cloud 是其中之一，所以试一下的成本只有注册本身。

Ollama Cloud 免费额度的限流是多少？

Ollama Cloud 没有公布单一的免费额度数字：它的限额形式是「有限流但未公布数值」。本清单在这里留空，而不是猜一个数。

Ollama Cloud 的 key 撞到限额会怎样？

端点返回 429。这只说明那一次请求被拒了，不说明还剩多少额度；只有服务商返回的 reset 响应头才能告诉你什么时候恢复。

Ollama Cloud 的免费额度会取消吗？

截至 2026-07-25，Ollama Cloud 自己的文档里没有这样的说法。随着新的开放权重模型发布，Ollama 会定期下线较旧的云端模型；本地模型不受这些下线影响。

Ollama Cloud 能配合 Codex、Cline 或 Continue 使用吗？

可以。Ollama Cloud 在 https://ollama.com/v1 上提供 OpenAI chat completions 协议，任何支持自定义 base URL 的客户端都能用。例外是 Claude Code，它讲的是 Anthropic 协议。
