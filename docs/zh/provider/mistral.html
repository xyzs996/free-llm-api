怎么验一个 Mistral La Plateforme 的 key

CORS 预检允许任意源携带 Authorization 请求头，所以浏览器可以直接调用这个端点。这一结论是 2026-07-25 针对 https://api.mistral.ai 实测得到的。

所以不用装任何东西，直接在浏览器检测页里就能验。如果你不愿意把 key 粘进网页，下面这条命令是等价的：

#!/usr/bin/env sh
set -eu

: "${MISTRAL_API_KEY:?Set MISTRAL_API_KEY to a key you created yourself at the provider console}"

# Prints the models this key can reach, then the HTTP status on its own line so
# 200, 401, and 429 stay distinguishable.
curl --silent --show-error \
  --write-out '\nHTTP %{http_code}\n' \
  --header "Authorization: Bearer $MISTRAL_API_KEY" \
  'https://api.mistral.ai/v1/models'

怎么用一个 Mistral La Plateforme 的 key

Mistral La Plateforme 在 https://api.mistral.ai/v1 上提供 OpenAI chat completions 协议。把任何支持自定义 base URL 的客户端指过去，并让客户端从 MISTRAL_API_KEY 读取 key，这样 key 本身永远不会落进配置文件：

# Merge this snippet into ~/.codex/config.toml.
# Project-level config cannot select a custom model provider.
model = "mistral-small-latest"
model_provider = "mistral"

[model_providers.mistral]
name = "Mistral La Plateforme OpenAI-compatible gateway"
base_url = "https://api.mistral.ai/v1"
env_key = "MISTRAL_API_KEY"
wire_api = "responses"

关于 Mistral La Plateforme 免费额度的常见问题

Mistral La Plateforme 需要绑信用卡吗？

不需要。本站有 23 家不用绑卡就能拿到免费访问，Mistral La Plateforme 是其中之一，所以试一下的成本只有注册本身。

Mistral La Plateforme 免费额度的限流是多少？

Mistral La Plateforme 没有公布单一的免费额度数字：它的限额形式是「有限流但未公布数值」。本清单在这里留空，而不是猜一个数。

Mistral La Plateforme 的 key 撞到限额会怎样？

端点返回 429。这只说明那一次请求被拒了，不说明还剩多少额度；只有服务商返回的 reset 响应头才能告诉你什么时候恢复。

Mistral La Plateforme 的免费额度会取消吗？

截至 2026-08-22，Mistral La Plateforme 自己的文档里没有这样的说法。Mistral 面向消费者的 Vibe 助手也有个 Free 计划，那是另一个产品；不要把助手的消息条数读成 API 的限额。

Mistral La Plateforme 能配合 Codex、Cline 或 Continue 使用吗？

可以。Mistral La Plateforme 在 https://api.mistral.ai/v1 上提供 OpenAI chat completions 协议，任何支持自定义 base URL 的客户端都能用。例外是 Claude Code，它讲的是 Anthropic 协议。
