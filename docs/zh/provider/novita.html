怎么验一个 Novita AI 的 key

CORS 预检允许任意源携带 Authorization 请求头，所以浏览器可以直接调用这个端点。这一结论是 2026-07-25 针对 https://api.novita.ai 实测得到的。

所以不用装任何东西，直接在浏览器检测页里就能验。如果你不愿意把 key 粘进网页，下面这条命令是等价的：

#!/usr/bin/env sh
set -eu

: "${NOVITA_API_KEY:?Set NOVITA_API_KEY to a key you created yourself at the provider console}"

# Prints the models this key can reach, then the HTTP status on its own line so
# 200, 401, and 429 stay distinguishable.
curl --silent --show-error \
  --write-out '\nHTTP %{http_code}\n' \
  --header "Authorization: Bearer $NOVITA_API_KEY" \
  'https://api.novita.ai/openai/models'

怎么用一个 Novita AI 的 key

Novita AI 在 https://api.novita.ai/openai 上提供 OpenAI chat completions 协议。把任何支持自定义 base URL 的客户端指过去，并让客户端从 NOVITA_API_KEY 读取 key，这样 key 本身永远不会落进配置文件：

# Merge this snippet into ~/.codex/config.toml.
# Project-level config cannot select a custom model provider.
model = "BAAI:BGE-M3"
model_provider = "novita"

[model_providers.novita]
name = "Novita AI OpenAI-compatible gateway"
base_url = "https://api.novita.ai/openai"
env_key = "NOVITA_API_KEY"
wire_api = "responses"

关于 Novita AI 免费额度的常见问题

Novita AI 需要绑信用卡吗？

不需要。本站有 23 家不用绑卡就能拿到免费访问，Novita AI 是其中之一，所以试一下的成本只有注册本身。

Novita AI 免费额度的限流是多少？

Novita AI 没有公布单一的免费额度数字：它的限额形式是「有限流但未公布数值」。本清单在这里留空，而不是猜一个数。

Novita AI 的 key 撞到限额会怎样？

端点返回 429。这只说明那一次请求被拒了，不说明还剩多少额度；只有服务商返回的 reset 响应头才能告诉你什么时候恢复。

Novita AI 的免费额度会取消吗？

截至 2026-08-22，Novita AI 自己的文档里没有这样的说法。从免费清单里移出，是因为免费的那几行没了，不是服务没了。批量推理有一个 50% 的入门折扣。

Novita AI 能配合 Codex、Cline 或 Continue 使用吗？

可以。Novita AI 在 https://api.novita.ai/openai 上提供 OpenAI chat completions 协议，任何支持自定义 base URL 的客户端都能用。例外是 Claude Code，它讲的是 Anthropic 协议。
