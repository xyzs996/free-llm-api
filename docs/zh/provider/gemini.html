怎么验一个 Google Gemini API 的 key

CORS 预检回显了发起请求的源，并允许 Authorization 请求头，所以浏览器可以直接调用这个端点。这一结论是 2026-07-25 针对 https://generativelanguage.googleapis.com 实测得到的。

所以不用装任何东西，直接在浏览器检测页里就能验。如果你不愿意把 key 粘进网页，下面这条命令是等价的：

#!/usr/bin/env sh
set -eu

: "${GEMINI_API_KEY:?Set GEMINI_API_KEY to a key you created yourself at the provider console}"

# Prints the models this key can reach, then the HTTP status on its own line so
# 200, 401, and 429 stay distinguishable.
curl --silent --show-error \
  --write-out '\nHTTP %{http_code}\n' \
  --header "Authorization: Bearer $GEMINI_API_KEY" \
  'https://generativelanguage.googleapis.com/v1beta/openai/models'

怎么用一个 Google Gemini API 的 key

Google Gemini API 在 https://generativelanguage.googleapis.com/v1beta/openai/ 上提供 OpenAI chat completions 协议。把任何支持自定义 base URL 的客户端指过去，并让客户端从 GEMINI_API_KEY 读取 key，这样 key 本身永远不会落进配置文件：

# Merge this snippet into ~/.codex/config.toml.
# Project-level config cannot select a custom model provider.
model = "gemini-2.5-flash"
model_provider = "gemini"

[model_providers.gemini]
name = "Google Gemini API OpenAI-compatible gateway"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai"
env_key = "GEMINI_API_KEY"
wire_api = "responses"

关于 Google Gemini API 免费额度的常见问题

Google Gemini API 需要绑信用卡吗？

不需要。本站有 23 家不用绑卡就能拿到免费访问，Google Gemini API 是其中之一，所以试一下的成本只有注册本身。

Google Gemini API 免费额度的限流是多少？

Google Gemini API 没有公布单一的免费额度数字：它的限额形式是「按项目层级设定」。本清单在这里留空，而不是猜一个数。

Google Gemini API 的 key 撞到限额会怎样？

端点返回 429。这只说明那一次请求被拒了，不说明还剩多少额度；只有服务商返回的 reset 响应头才能告诉你什么时候恢复。

Google Gemini API 的免费额度会取消吗？

截至 2026-07-25，Google Gemini API 自己的文档里没有这样的说法。新项目默认处于 Free 层级。只有部分模型带免费用量，按模型的具体限额在 AI Studio 里可以看到。

Google Gemini API 能配合 Codex、Cline 或 Continue 使用吗？

可以。Google Gemini API 在 https://generativelanguage.googleapis.com/v1beta/openai/ 上提供 OpenAI chat completions 协议，任何支持自定义 base URL 的客户端都能用。例外是 Claude Code，它讲的是 Anthropic 协议。
