## 需求调研与关键结论

- `src/validate.js` 定义的 `browser_check` 状态为 `supported`、`blocked`、`unverified`；现有指南遗漏了 `unverified`。
- `src/probe-contract.js` 要求 `not-checked` 时七个测量字段为 `null`，但 `classification` 和 `explanation` 仍必须是非空字符串；现有“全部为 null”的表述不准确。
- `models` 可同时包含可粘贴的 API model id 与目录范围说明；`src/snippets.js` 会过滤出符合 `MODEL_ID_PATTERN` 的值生成配置。
- `.github/workflows/ci.yml` 运行 `npm test`、`npm run validate`、`npm run check` 和 `npm run render:check`；CI 不运行会写入产物的 `npm run render`。
- `data/changelog.json` 中的变更项除 `type` 和 `detail` 外还必须填写 `provider_id`。
- `docs/` 是渲染产物目录，因此本任务记录放在 `tasks/` 中，避免与产物生成规则冲突。
